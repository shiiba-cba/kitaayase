# 千代田線 北綾瀬 時刻表アプリ（Kitaayase Timetable）

東京メトロ千代田線 **北綾瀬駅発着** に特化した、スマートフォン向けの時刻表 Web アプリです。  
北綾瀬支線・綾瀬 0 番線・3 両編成（96S 列車）など、**一般的な時刻表では分かりづらい情報**を分かりやすく表示することを目的としています。

👉 公開ページ  
https://shiiba-cba.github.io/kitaayase/

---

## 特徴

- 🚉 **北綾瀬発着に特化**
- 🔁 A線（代々木上原方面）／B線（北綾瀬方面）切り替え
- 📅 **平日 / 土・休日** の自動判定（4:00 を一日の始まりとして扱う）
- 🕓 **現在時刻に自動スクロール**
- ⚠ 途中駅止まり・当駅始発列車・綾瀬始発列車・3 両編成（96S）の視覚的判別
- 📱 スマートフォンでの視認性を重視した UI
- 🧩 GitHub Pages で動作する **完全サーバーレス構成**

- 東京メトロ 千代田線
  - 代々木上原方面

## 運行情報について

現在、**運行情報の取得・表示機能は有効**です。

東京メトロ オープンデータ API を  
**Cloudflare Workers 経由でリアルタイムに取得**し、  
アプリ側からはその API を参照しています。

### 現在の構成

- Cloudflare Workers を用いた API プロキシを運用
- 東京メトロ オープンデータ API（v4）から運行情報を取得
- APIキーは Workers 側で安全に管理（クライアントには非公開）
- Edge Cache（`Cache-Control: max-age=30`）により
  - 外部 API への負荷を軽減
  - アクセス集中時も安定したレスポンスを提供

アプリは以下のように運行情報を取得します：

- アプリ → Cloudflare Workers → 東京メトロ API

### この構成を採用した理由

- GitHub Actions の cron 実行は安定性に課題がある
- 毎分〜数十秒間隔での取得には不向き
- クライアントから直接 API を叩くと APIキーを秘匿できない

これらの問題を回避するため、  
**サーバーレスで常時稼働する Cloudflare Workers** を採用しています。

## 設計上の考慮点

- **一日の始まりを 4:00 として扱う**
  - 終電後〜始発前でも自然な表示になるよう調整
- 表示上の誤認を防ぐため：
  - 綾瀬始発の列車
  - 途中駅止まりの列車
  - 3 両編成
  を明示的に表示
